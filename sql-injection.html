[ MOD-03 · SQLi ]

SQL Injection Range

This is a simulated login form. Try to break it with an injection payload, then flip to the safe version and see why it holds.

Vulnerable Login

Query built by string concatenation:

SELECT * FROM users WHERE username = '' AND password = ''

Safe Login

Prepared statement — user input is bound as data, never concatenated. 

$stmt = $conn->prepare("SELECT * FROM users WHERE username = ? AND password = ?");
$stmt->bind_param("ss", $username, $password);
$stmt->execute();
